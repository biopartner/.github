# Bio Partner Schweiz AG 🌱

Herzlich Willkommen auf der **Bio Partner Schweiz AG** Github Organisation.

Die **Bio Partner Schweiz AG** arbeitet mit einer vielfältigen Applikations- und Integrationslandschaft.
Diese GitHub Organisation unterstützt die Entwicklung und Integration von Softwarelösungen für die **Bio Partner Schweiz AG**.

🌐 **Unternehmenswebsite:** https://www.biopartner.ch

---

## 📦 Entwicklungsprojekte

Unsere Entwicklungsprojekte umfassen unter anderem:

- ERP Erweiterungen
- Projekte mit weiteren Business-Applikationen
- APIs und Schnittstellen

---

### 🧩 Infor M3

Der Schwerpunkt dieser GitHub Organisation liegt auf der Weiterentwicklung der Benutzeroberfläche des ERP-Systems Infor M3.

Dazu gehören unter anderem:

- H5 Skripte
- H5 Applikationen
- Widgets

---

### 🔗 APIs & Integrationen

Unsere Systeme werden über verschiedene Schnittstellen und Integrationen miteinander verbunden.
Zur Umsetzung und Weiterentwicklung dieser Lösungen bestehen Projekte in den folgenden Bereichen:

- Azure Functions
- Infor ION

---

### 👥 Business Applications

Neben unserer Infor-Landschaft betreiben und entwickeln wir weitere Business-Applikationen.
Derzeit erfolgt die Einführung eines CRM-Systems.

## 🔐 Sicherheit

Viele Repositories enthalten interne Geschäftslogik, Konfigurationen oder Integrationen und sind daher **nicht für die öffentliche Weitergabe bestimmt**.

Bitte beachte beim Arbeiten mit diesen Repositories insbesondere:

- Keine Passwörter oder Secrets in Git einchecken
- Keine vertraulichen Daten in Source Code oder Dokumentationen hinterlegen
- Keine Kunden- oder Personendaten unnötig in Repositories speichern
- Zugriffsrechte entsprechend der internen Vorgaben vergeben
- Produktionskonfigurationen nicht unkontrolliert versionieren
